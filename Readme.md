- UIの調整がしやすいように極力tscnファイルに直接ノードを配置する

## タイトル
強奪え！魔法少女ばいお

## コンセプト
- 1対1のメギド72みたいなゲームを作ろう！
- 共通の資源を奪い合うことで相手の行動を妨害したり、自分の有利な行動を取ったりできる
- ピーキーな行動をとる敵に対応した動きで柔軟に戦おう！
- ストーリーはギャグチックかつ簡潔に進ませる

## 仕様
- 魔法少女が敵を倒していくターン制RPG
- 毎ターン補充される共通の資源（魔力）を交代性で取り合う
- 取った資源によって対応する行動ができる
  - 資源は3種類あり、攻撃(消すかも)、スキル、必殺チャージができる
  - スキルは何種類からか選ぶ（ローグライク要素？）
  - 必殺チャージが最大になると必殺技が撃てる
	- 必殺技はチャージに時間がかかるがほぼ勝ち確定にしたい
- ゲームはステージ制で、4ステージを想定している
- 自分と敵は攻撃に耐えられる回数（体力）がそれぞれある
- 敵の体力を削り切ったら勝ち、それより先に自分の体力が無くなったら負け
- 負けたステージからリトライできる

## 魔力効果
- 通常攻撃：キャラクターの攻撃力に応じたダメージ
- スキル：キャラクターに応じたスキルが発動する
- チャージ：必殺チャージ2増加

## 主人公能力
- HP：50
- 通常攻撃：敵に5ダメージ
- スキル：強奪（敵に5ダメージ、敵の必殺チャージを1奪う）
- チャージ：必殺チャージ2増加
- 必殺技：チャージ8で発動、敵に10ダメージ

## 装備可能特性
通常攻撃、スキル、チャージに一つずつ装備可能
- 必殺チャージ＋1追加
- HP5回復
- 通常攻撃を一回追加

## 戦闘準備フェーズ
- 主人公をスキルビルドできるようにする
- スキルをセットできる（最初から3つ所持）
  - 強奪（敵に5ダメージ、敵の必殺チャージを1奪う）
  - 猛毒（敵を猛毒状態にして、毎ターン終了時に2＋猛毒になってからの経過ターン数ダメージ）
  - スキルチャージ（必殺チャージ2増加）
- 通常攻撃、スキル、チャージそれぞれに1つずつ効果を選択できる

## 戦闘画面
- 画面左に主人公、画面右端に敵が向かい合う形で描画される
- 中央に共有リソース（魔力）がターン開始時3種類の中からランダムに縦5つ発生する

## 戦闘システム
- クリックで取りたい魔力を選択、もう一度クリックで確定
- 敵は独自ロジックで取得する魔力に優先度をつける
- 1ターン目は主人公先行でターン事に敵と先行が入れ替わる
- チャージが最大以上の状態になると必殺技が発動

## 戦闘終了後
- 毎回HPは全回復する
- 敵の能力を強奪できる

## 敵設計
- 第一ステージ
  - スライム
  - 敵体力20
  - 攻撃力：5
  - 必殺ゲージ：8
  - 攻撃を優先して取る　無い場合はランダム
  - スキル：魔力吸収（相手の魔力チャージを2減らして自分の魔力チャージを1増やす）
  - 必殺技：体当たり（相手に10ダメージ）
  - 撃破時の取得スキル：魔力吸収
- 第二ステージ
  - コウモリ男
  - 敵体力50
  - 攻撃力：10
  - 必殺ゲージ：10
  - スキル＞チャージ＞攻撃の順に優先して取る
  - スキル：吸血（相手に５ダメージを与えて3回復）
  - 必殺技：再生（体力を全回復させる）
  - 撃破時の取得スキル：吸血
- 第三ステージ
  - えんじぇるん
  - 敵体力80
  - 攻撃力：8
  - 必殺ゲージ：8
  - スキル＞チャージ＞攻撃の順に優先する
  - スキル：バリア（1回ダメージ無効　毒ダメージも含む。有効中は重ねがけ不可）
  - 必殺技：エンジェルアロー（30ダメージ＋自身10回復）
  - 撃破時の取得スキル：バリア（1回ダメージ無効。有効中は重ねがけ不可）
- 第四ステージ
  - 魔法少女ぎふと
  - 敵体力100
  - 攻撃力：10
  - 必殺ゲージ：10
  - チャージ＞スキル＞攻撃の順に優先して取る
  - スキル：プレゼント（自分の体力を10回復）
  - 必殺技：デスギフト（相手に50ダメージ）
